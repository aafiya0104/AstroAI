# Astro

See the threat before it sees you — real-time URL and email analysis, powered by heuristics and machine learning.
Every link gets a clear, explainable risk score, so you know exactly why it's flagged, not just that it is.
Fast. Lightweight. Effortless protection, built right into your browser.


## Problem Statement

**Background**
Phishing remains one of the most common entry points for cyberattacks, and most users have no quick way to verify whether a link or email is safe before clicking.

**Objective**
Build a browser extension or web application that analyzes URLs and emails in real time, flagging phishing attempts using a combination of heuristics (domain age, structural red flags, etc.) and a trained ML classifier. The tool should present a clear risk score along with a short explanation of why a link was flagged.

**Suggested Focus Areas**
- Real-time URL/email scanning
- Heuristic + ML-based classification
- Risk score with explanation
- Lightweight, user-friendly interface (extension or web app)
